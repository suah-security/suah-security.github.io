**Learn by Building. Validate by Testing. Document the Process.**

A personal engineering portfolio and technical lab focused on cloud security, security automation, and AI security. Work is documented through independent, reproducible environments.

## Planned Projects

### 01 — Multi-Cloud Security Baseline & Automation

**AWS · Google Cloud · Microsoft Azure**

Plan to implement and validate common security controls across three cloud providers, including IAM, network exposure, storage access, audit logging, and encryption. Infrastructure as Code, automated checks, and remediation evidence are intended to support reproducible comparisons.

### 02 — AI Security Assessment & Runtime Defense

Plan to build an isolated RAG/agent test application, assess relevant threats, and evaluate runtime safeguards. Results will distinguish observed outcomes from proposed controls and untested assumptions.

### 03 — Kubernetes Security Platform (Follow-up)

Planned work on Kubernetes RBAC, workload security, and policy validation after the primary projects.

## Engineering Workflow

1. **Design:** Define the problem, threat model, security objectives, and scope.
2. **Build:** Implement a reproducible lab in an authorized environment.
3. **Validate:** Test controls, capture before/after evidence, and record limitations.
4. **Document:** Publish architecture, methodology, verification steps, and lessons learned.
